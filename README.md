# SBA 9 — Task Management Dashboard

A responsive task management dashboard built with React, TypeScript, Vite, and Tailwind CSS. Users can organize tasks, track progress, and manage task data through an interactive interface.

## Features

1. **Task Management:** Add, edit, delete, and update task statuses.
2. **Search and Filtering:** Search tasks and filter by status or priority.
3. **Sorting and Reordering:** Sort by date or priority and manually rearrange tasks.
4. **Dashboard Statistics:** View total, pending, in-progress, and completed tasks, including completion rate.
5. **Data Persistence:** Save tasks and theme preferences with localStorage.
6. **Light/Dark Mode:** Switch between two dashboard themes.
7. **Import/Export:** Download and restore task data using JSON files.

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Vite
- HTML and CSS
- JavaScript localStorage

## Getting Started

Install dependencies:

`npm install`

Start the development server:

`npm run dev`

Open the local URL displayed in the terminal. Then:

`npm run build`

## Reflection

Building this dashboard strengthened my understanding of React components, TypeScript interfaces, state management, and event handling. I practiced creating reusable components, passing props, and updating arrays without directly modifying state.

One challenge was implementing Light/Dark Mode while keeping form labels, dropdowns, and task cards readable. I resolved this by improving Tailwind styling and testing both themes.

I also learned how to persist tasks using localStorage, validate imported JSON data, and manage manual task reordering alongside sorting and filtering.

Although I still struggle with some concepts presented, this project helped me become more knowledgable in building interactive React applications.
